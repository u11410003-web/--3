【實習照片存放資料夾】
您可以直接把您的實習照片（例如手機拍攝的敲擊照片、儀器照片、全組同學合照）丟進這個 images 資料夾！

建議命名方式：
- hammer_shot.jpg (敲擊鐵鎚與鋼板照)
- das1_screen.jpg (震測儀主機與波形螢幕照)
- geophones_lawn.jpg (草坪檢波器排列照)
- team_photo.jpg (全組同學合照)

放進來之後：
1. 打開 index.html
2. 搜尋「images/」，把裡面的檔名改成您的照片檔名（例如 src="images/hammer_shot.jpg"）
3. 只要把整個專案資料夾上傳到 GitHub，您的所有照片與心得就 100% 永久保存在 GitHub 伺服器上了！
   全球任何人都看得到，不會只存在自己電腦！
