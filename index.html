📐 原理介紹：看不見的地下，我們怎麼知道？

地震波傳播機制與初至波 (First Arrival)

當鐵鎚猛烈敲擊地表鋼板時，會在介質中激發多種波動形式：

壓縮波 (P-wave / 縱波)

質點振動方向與波傳播方向平行。傳播速度最快，永遠最先到達受波器。在折射震測中，我們只拾取 P 波的最先偏折點作為「初至波 (First Break)」，以確保不受後續波形干擾。

剪力波 (S-wave / 橫波)

質點振動方向與波行進方向垂直，速度約為 P 波的 0.5~0.6 倍，且無法在流體中傳遞。到達時間晚於初至 P 波，常與地表波混雜。

表面波 (Rayleigh / 地表滾波)

沿自由地表傳播，能量衰減慢、振幅極大但速度最慢，頻率通常較低 (10~25 Hz)。在折射震測中被視為干擾訊號 (Ground Roll)。

司乃耳定律 (Snell's Law) 與臨界角折射

地震波通過兩個速度相異的地層界面時，其入射角 $\theta_1$ 與折射角 $\theta_2$ 遵循波動光學之司乃耳定律：

sin θ₁ / V₁ = sin θ₂ / V₂
其中 V₁ 為表層速度，V₂ 為下層高速介質速度（前提條件：V₂ > V₁）。

當入射角增大至某個特定角度時，折射角達到 90°（$\theta_2 = 90^\circ, \sin\theta_2 = 1$），此特定入射角即稱為臨界角 (Critical Angle, $\theta_c$)：

θ_c = arcsin(V₁ / V₂)
當波以臨界角入射時，波將沿著地層界面以高速 V₂ 傳播，並在傳播過程中不斷以臨界角 $\theta_c$ 向地表輻射能量，形成頭波 (Head Wave / 側波)！這正是遠端受波器能夠比直達波更早接收到訊號的物理本質。

走時方程式推導與深度計算公式

折射震測透過分析地表受波器測得的「距離 (x) 與走時 (T)」關係，分別建立兩種波的走時直線：

1. 直達波 (Direct Wave) 走時方程式
T_direct = x / V₁
波直接沿地表傳播，走時曲線通過座標原點 (0,0)，其斜率為 1 / V₁。
2. 臨界折射波 (Refracted Wave) 走時方程式
T_refract = (x / V₂) + t_i
波下行以 V₁ 入射、在界面以 V₂ 行進、再上行輻射至地表。走時曲線斜率為 1 / V₂，Y 軸截距為 t_i (Intercept Time)。
3. 截距時間法 (Intercept-Time Method) 地層深度公式
h = (t_i / 2) · [ (V₁ · V₂) / √(V₂² - V₁²) ]
其中截距時間 $t_i = 2h \cos(\theta_c) / V_1$。只要由走時曲線圖外推求得 $t_i$ 並由兩線斜率求出 $V_1$ 與 $V_2$，便能精確解出界面深度 $h$。
4. 交錯距離法 (Crossover Distance Method)
X_co = 2h · √[ (V₂ + V₁) / (V₂ - V₁) ] ⇒ h = (X_co / 2) · √[ (V₂ - V₁) / (V₂ + V₁) ]
交錯距離 $X_{co}$ 為直達波與折射波走時相等（折射波反超直達波）之距離點。在此距離之外，折射波率先抵達，成為初至波！

折射震測的基本假設與地質限制

折射震測法在工程地質應用上極具成效，但在解釋模型時必須充分考量下列假設與限制：

  • 速度遞增原則 ($V_2 > V_1$)：臨界折射波必須在下層速度大於上層速度時才能形成。若下層速度較慢，折射波將偏向法線向下偏折，永遠無法返回地表。
  • 速度倒轉層 (Velocity Reversal / 低速夾層)：若地下存在含水飽和夾層或軟弱泥層導致波速變慢，折射震測無法測得該層的存在，會導致計算出的下伏基盤深度偏大。
  • 盲層 (Hidden Layer / 薄層效應)：若中層厚度過薄或與上下層速度差異不足，該層的折射波在走時圖上永遠不會超前成為「第一抵達者」，導致資料分析時漏失該層資訊。
  • 橫向均質性與傾斜地層：單一砲點僅能求得視速度 (Apparent Velocity)；本實驗共布設 12 砲，可透過雙向逆向打砲 (Forward & Reverse shooting) 修正傾斜界面 (Dipping interface) 之真速度與真傾角。

PART 05 / STUDENT REFLECTION & JOURNAL

✍️ 心得感想與野外實習影像紀錄

記錄野外實作體驗、敲擊鐵鎚時的物理反思、雜訊干擾排除及科學建模收穫。

實作者：第四個測試者 (Shot 104 · 12m 敲擊) 實習日期：2026 年 10 月 7 日

一、 敲擊震源與野外體能實踐

在本次實習中，我有幸擔任「第四個測試 (Shot 104，炸點位於 12m)」的操作敲擊者。站在圖書館後方草坪上，雙手握緊 12 磅鐵鎚準備下擊時，深刻體會到人工震源的嚴謹性：揮鎚不僅需要充足的臂力，更必須維持精準垂直的打擊軌道，才能將動能最大化轉換為垂直壓縮的 P 波，並避免底板橫向滑動產生複雜的剪力雜波。

二、 絕對時間錨定與 Trigger 機制

敲擊瞬間，安裝於鐵鎚頭部的微動觸發開關（Trigger switch）受到接觸衝擊閉合，即時向 DAS-1 數位主機送出電脈衝，將敲擊時刻定義為絕對零點 $t = 0$。在課堂上這只是一個抽象的物理符號，但在現場看到螢幕上的 24 道波形以這瞬間為起點同步開始計時，真切感受到「沒有精確的時間基準，一切距離與走時計算皆無法成立」的科學真理。

三、 野外環境雜訊排除與 Stacking（多次疊加）技術

由於測線緊鄰市區要道（重慶南路與愛國西路），公車與車輛行經時會在地面引起顯著的低頻滾波（Ground roll）與隨機震動。在操作過程中，我們透過重複在同一炸點敲擊並進行多次數位疊加（Stacking = 15 次），利用非同相環境隨機雜訊互相抵消、同相有效地震訊號線性增強的原理，成功讓遠道受波器微弱的頭波訊號清晰浮現，體會到信噪比（SNR）在地球物理探勘中的關鍵價值。

四、 資料分析與地質速度建模印證

回到室內進行 104.dat 資料處理時，將 24 道初至時間繪製成 T-X 走時曲線，直達波與臨界折射波的交錯特徵令人驚嘆！在近距離處波速為 $358\text{ m/s}$，如實反映了校園草坪鬆散、多孔隙之人工回填土層；而當距離超過 $14\text{ m}$ 後，折射波以 $780\text{ m/s}$ 的高速度反超成為初至波。透過截距時間法推算出第一層風化土厚度約 $3.83\text{ 公尺}$，與臺北盆地松山層表層工程地質條件完全吻合。

五、 探究總結：看不見的地下，我們怎麼知道？

整個實習不是單純的儀器操作，而是一場標準的科學建模歷程。我們雖然無法肉眼透視地底，但藉由「激發訊號 $\to$ 記錄到時 $\to$ 幾何走時擬合 $\to$ 解算地下速度與邊界」，以扎實的觀測證據建立起對未知的地下構造認知。這次實習將課本上的波動方程式化為手中震動的脈衝與具體數據，獲益良多！

🚀 GitHub Pages 快速部署教學指南

本報告為純靜態架構（index.html, style.css, app.js, data.js, 圖片檔），完全不需要安裝 Node.js 或執行 Build 指令，直接上傳即可 100% 運作！

方法一：GitHub 網頁直接拖曳上傳（最簡單，免裝任何軟體）

  1. 登入 GitHub.com，點擊右上角「New」建立一個新的 Repository（例如命名為 seismic-report，設為 Public）。
  2. 在建立好的倉庫頁面，點擊「uploading an existing file」。
  3. 將資料夾內的所有檔案（index.html, style.css, app.js, data.js, 以及圖片檔）全部拖曳進去，點擊「Commit changes」。
  4. 點擊倉庫上方的「Settings」→ 左側「Pages」。
  5. 在「Branch」選取 main（或 master），資料夾選 /(root)，點擊「Save」。
  6. 稍等約 1 分鐘，重新整理頁面，即可看到綠色勾勾顯示您的專屬網址：
    https://<您的帳號>.github.io/seismic-report/
